First, install the dependencies: `pip install -r requirements.txt`
Then, make sure that the required data files exist in the project, for example:
data/
Results_21Mar2022.csv
treemap_data.csv
radar_data.csv
scatter_matrix_data.csv
And configure the .env file.
Then run:
app.py
The default running address is:
http://127.0.0.1:5000
